# Finance Operations Automation Suite

## Overview

The Finance Operations Automation Suite (FOAS) is an enterprise-grade Microsoft Power Platform solution that automates purchase request and approval processes.

The solution demonstrates:

- Power Apps
- Power Automate
- Power BI
- SharePoint / Dataverse
- Microsoft Teams integration
- Outlook integration
- REST API integrations
- Custom Connectors
- Security and governance
- Documentation
- CI/CD with GitHub
